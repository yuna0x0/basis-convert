  type are still listed. `DestroyEditorOnlyInAvatar` still runs before a build.
- `JIGGLE_VALIDATE` left the scripting defines. Nothing in the package references it.
- The blendshape stripper call in `BasisAvatarSDKInspector` is still commented out, so the
  `BasisBlendshapeBuildHooks` item in the 2026-09-02 Later list has not started.
- `BasisAvatar`, `AvatarSDKVisemes`, `BasisAuthoredMotion`, `BasisMotionClip` and the HVR Vixxy
  types were not touched.
