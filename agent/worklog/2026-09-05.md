## Colliders, checked against the sources

Asked whether VRM spring bone colliders reach the jiggle rig. They do: a probe over both
AvatarSample_B files matched every spring's collider count to the plan and all 212 planned
entries to the source radius and offset. VRChat's do too; the Shinano scene holds 105 rigs
carrying them. Checking the semantics against the decompiled SDK and the jiggle job found two
things the tests could not:

- **Capsule height.** VRChat and Dynamic Bone give it end to end and treat a capsule no taller
  than its diameter as a sphere; jiggle measures between the cap centres. Every converted capsule
  was a diameter too long. Fixed in both mappers; the VRM one was already right, since VRM states
  the two centres.
- **Plane orientation.** VRChat rotates a plane, Dynamic Bone picks its axis, VRM states its
  normal. A jiggle plane faces its transform's Y and has no field for anything else, so a plane
  facing another way was written facing Y without a word. Now reported on all three sources.
  Nothing else can be done short of writing a helper transform, which is not started.

Details in `agent/research/physbone-to-jiggle-mapping.md`. Eight new tests in
`ColliderShapeTests`.

## VRChat SDK 3.10.5, and the versions line

Downloaded 3.10.5 and 3.8.0 into the scratchpad (nothing goes near the Basis project),
decompiled both, and diffed every class the readers touch. Descriptor, menus, parameters and the
constraints are unchanged. New since 3.8: global PhysBone colliders, box contacts, VRC Raycast,
per-platform overrides, impostor settings. All now recognised: the first as
`collider.global.dropped`, raycasts as `raycast.dropped`, the build settings as
`vrchat.buildSettings`. Contacts of any shape were already `contacts.dropped`.

The diff also showed VRCHeadChop, from 3.6, which the table had never had: it was reported as an
unknown script. Basis has `BasisHeadChop` with the same shape, so it converts now: reader,
mapper, writer, wired in with the descriptor. The VR-only and desktop-only conditions are
reported. Six tests on the sample avatar, which gained a head chop, a raycast and a per-platform
override.

`ProductInfo.CheckedAgainst` names the source versions the readers were checked against. The
report's first line, the window's footer and a docs page repeat it. The procedure for the next
SDK release is in `agent/research/vrchat-serialized-formats.md`.

## 0.5.1

The versions footer did not wrap: it went through `WrappedLabel` with `EditorStyles.miniLabel`,
whose `wordWrap` is off, and the helper used the style as given. The helper now forces word wrap
