# 2026-09-01

Released 0.2.0, then cut the changelog in half and wrote down why.

## 0.2.0 is out

Tagged `v0.2.0`, signed, and live on all three channels: the GitHub release (zip,
`.unitypackage`, signed `.tgz` with a Unity attestation, and the bare `package.json`), the VPM
listing at `vpm.yuna0x0.com`, and the docs site. OpenUPM picks it up on its own poll.

The listing needed a manual `workflow_dispatch`. Its build only triggers on a `source.json`
push, and a release does not touch that file, so the index keeps serving the old version until
someone runs the workflow. Worth remembering at the next release.

Three claims on the docs site had been left behind by the VRM work and were fixed before the
tag: the homepage meta description still named props and omitted VRM, a feature card said
VRChat constraints, and the limitations page listed a VRM's first-person settings and metadata
as not converted at all, when the eye offset carries across and the metadata is shown before
converting.

## The changelog was too long

The 0.2.0 section ran 88 lines for 25 entries, each one a paragraph explaining why. Rewritten
to 45 lines, same entries, one line each. The published release notes were replaced too.

`AGENTS.md` gains a **Write short** section, because this had come up three times. The rule:
one line per changelog entry, a second only for a diagnostic code or a caveat a user would
hit, and the reasoning goes to `agent/decisions/` or here instead.

## Synced the Basis clone

Upstream had three commits (foveated VRS rework, the Steam release, a render pipeline change).
`developer` fast-forwarded; `yuna0x0` had the avatar commit rebased onto it and force-pushed to
gitgud, after checking the rebased commit's change set matched the original across all 2276
files. `basis-convert-dev` now sits on the rebased tip, so work happens against current Basis.

`fix/camera-tests-android-gi-guard` is deleted; it landed upstream as #1024. The fork's copy
was already gone, so only the local branch and a stale tracking ref remained.

Watch out: the working tree in that clone is never clean, and one dirty file collides with
upstream. `Poppins-Regular SDF NamePlate.asset` is a regenerated font atlas that upstream also
edits, so it conflicts on a stash pop. Discard the local copy before stashing.
`Assets/yuna0x0/Avatars/Shinano/Shinano.unity` is not churn and has to survive.
